# unused-vars cleanup batch 2

## Rules
1. Use `edit` tool only - one file at a time
2. `catch (e)` → `catch` when `e` is unused (5 files)
3. Unused imports → remove from import statements
4. Unused type/const/let/var declarations → remove entire line
5. **DO NOT change any logic** - only remove dead code
6. After each file, run `npm run lint 2>&1 | Select-String "no-unused-vars" | Measure-Object | ForEach-Object { $_.Count }` to track progress
7. Git commit after all done
