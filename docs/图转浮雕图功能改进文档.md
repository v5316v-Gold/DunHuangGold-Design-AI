# 图转浮雕图功能改进文档

## 修改概述

本次修改让"图转浮雕图"功能的三个核心选项真正生效：
1. **浮雕类型**（浅浮雕 / 深浮雕）
2. **模型权重**（0-100滑块）
3. **下载格式**（PNG / EXR / VSM）

## 概念理解

### 1. 浮雕类型
- **浅浮雕**：浮雕深度较浅，图案接近背景平面，对比度低，适合精细图案
  - 实现：Meshy API 中使用 `surface_mode: 'smooth'` 参数
- **深浮雕**：浮雕深度较深，立体感强，对比度高，适合需要强烈视觉冲击
  - 实现：Meshy API 中使用 `surface_mode: 'sharp'` 参数

### 2. 模型权重
- 控制生成的忠实度，范围 0-1
- **高权重（>0.7）**：更忠实原图，减少重网格
- **低权重（<0.3）**：更多 AI 创造，增加重网格
- 实现：通过 Meshy API 的 `should_remesh` 参数控制

### 3. 下载格式
- **PNG**：浮雕预览图（普通图片格式）
- **EXR**：高动态范围深度图（需要3D渲染支持）
- **VSM**：特殊格式（3D模型，兼容VSM）
- 实现：通过新建的 `/api/relief-download` 接口处理

## 代码修改详情

### 1. 后端 API 修改

#### `/workspace/projects/src/app/api/relief/route.ts`
- 新增接收参数：`reliefType`, `modelWeight`, `downloadFormat`
- 将参数传递给 `meshyImageToRelief` 函数
- 修改返回数据结构，将 `modelUrl`, `depthMap` 等放入 `data` 对象

#### `/workspace/projects/src/app/api/relief-download/route.ts`（新建）
- 实现格式转换和下载逻辑
- 根据不同格式返回不同的下载URL和文件名
- EXR格式：返回深度图（如果有）
- VSM格式：返回3D模型（GLB格式）

### 2. Meshy API 服务层修改

#### `/workspace/projects/src/lib/meshy-api.ts`
- 扩展 `MeshyConfig` 接口，新增字段：
  - `reliefType?: 'shallow' | 'deep'`
  - `modelWeight?: number`
  - `downloadFormat?: 'png' | 'exr' | 'vsm'`
- 修改 `createReliefTask` 函数：
  - 根据 `reliefType` 设置 `surface_mode`
  - 根据 `modelWeight` 设置 `should_remesh`

### 3. 前端组件修改

#### `/workspace/projects/src/components/workspace/ReliefDesign.tsx`
- 新增状态：`modelUrl`, `depthMap`
- 修改 `handleGenerate` 函数：
  - 传递正确的参数到后端
  - 保存返回的模型URL和深度图
- 修改 `handleDownload` 函数：
  - 调用新的 `/api/relief-download` 接口
  - 根据不同格式下载不同类型的文件
- 修改 `handleClearImage` 函数：
  - 清除模型URL和深度图

## 使用说明

### 用户操作流程

1. **上传图片**：点击上传区域，选择参考图片
2. **选择浮雕类型**：
   - 点击"浅浮雕"按钮，生成表面平滑的浮雕
   - 点击"深浮雕"按钮，生成表面锐利的浮雕
3. **调整模型权重**：
   - 拖动滑块，调整生成强度
   - 向右拖动（高权重）：更忠实原图
   - 向左拖动（低权重）：更多AI创造
4. **选择下载格式**：
   - PNG：下载预览图
   - EXR：下载深度图（如果有）
   - VSM：下载3D模型
5. **生成浮雕**：点击"开始生成"按钮
6. **下载结果**：点击下载按钮，下载相应格式的文件

### 技术实现细节

#### 浮雕类型映射
```typescript
// 浅浮雕
surfaceMode = 'smooth'

// 深浮雕
surfaceMode = 'sharp'
```

#### 模型权重映射
```typescript
// 高权重（>0.7）
shouldRemesh = false  // 不重网格，更忠实原图

// 低权重（<0.7）
shouldRemesh = true   // 重网格，更多AI创造
```

#### 下载格式映射
```typescript
// PNG 格式
返回：previewImage
文件名：relief-{type}-{timestamp}.png

// EXR 格式
返回：depthMap（如果有），否则返回modelUrl
文件名：relief-{type}-depth-{timestamp}.exr

// VSM 格式
返回：modelUrl
文件名：relief-{type}-model-{timestamp}.glb
```

## 已知限制

1. Meshy API 可能不直接支持 EXR 格式的深度图，需要根据实际API返回调整
2. VSM 格式实际上是返回 GLB 格式的 3D 模型，需要向用户说明
3. 模型权重的影响可能不够明显，需要根据用户反馈调整阈值
