## 测试结果

### 测试1：4K分辨率 + 16:9宽屏

**输入参数**：
```json
{
  "resolution": "4k",
  "ratio": "16:9"
}
```

**API转换结果**：
```json
{
  "outputResolution": 4096,
  "aspectRatio": "16:9",
  "textureResolution": "high"
}
```

**说明**：
- 分辨率4K → Meshy API使用 `texture_resolution: 'high'`，输出4096x4096
- 比例16:9 → Meshy API使用 `aspect_ratio: 1.777`，保持16:9宽屏

## 代码实现验证

### MeshyConfig接口

```typescript
interface MeshyConfig {
  // ... 其他参数
  resolution?: '1k' | '2k' | '4k';
  ratio?: string;
}
```

### 参数转换逻辑

```typescript
// 分辨率转换
let outputResolution = 1024;
if (config.resolution === '1k') {
  outputResolution = 1024;
} else if (config.resolution === '2k') {
  outputResolution = 2048;
} else if (config.resolution === '4k') {
  outputResolution = 4096;
}

// 比例转换
let aspectRatio = null;
if (config.ratio && config.ratio !== 'auto') {
  const parts = config.ratio.split(':');
  if (parts.length === 2) {
    const width = parseInt(parts[0]);
    const height = parseInt(parts[1]);
    if (width > 0 && height > 0) {
      aspectRatio = width / height;
    }
  }
}
```

### Meshy API请求

```typescript
{
  image_url: image,
  mode: 'preview',
  style: 'realistic',
  should_remesh: false,
  enable_pbr: false,
  generate_depth_map: true,
  texture_resolution: config.resolution === '4k' ? 'high' : config.resolution === '2k' ? 'medium' : 'low',
  ...(aspectRatio && { aspect_ratio: aspectRatio })
}
```
