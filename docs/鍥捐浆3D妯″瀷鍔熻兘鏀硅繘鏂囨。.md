# 图转3D模型功能改进文档

## 修改概述

本次修改让"图转3D模型"功能的三个核心选项真正生效：
1. **模型面数**（2m, 1.5m, 1m, 500k）
2. **模型类型**（几何+纹理 / 几何白模）
3. **几何精度**（标准 / 超清）

同时实现了**文生3D**功能，支持通过文字描述生成3D模型。

## 概念理解

### 1. 模型面数
3D模型由三角形面组成，面数越多模型越精细，但文件也越大：
- **2m**（200万面）：最高精度，细节最丰富，适合高质量渲染
- **1.5m**（150万面）：高精度，细节丰富
- **1m**（100万面）：中等精度，平衡性能和细节
- **500k**（50万面）：低精度，性能好，适合快速预览

**实现**：通过 Meshy API 的 `resolution` 参数控制
- 2m/1.5m → `resolution: 'high'`
- 1m → `resolution: 'medium'`
- 500k → `resolution: 'low'`

### 2. 模型类型
控制模型的材质和纹理：
- **几何+纹理**：带有材质贴图的模型，有颜色和纹理信息，适合真实感渲染
- **几何白模**：纯白色模型，只显示几何结构，适合查看模型结构

**实现**：通过 Meshy API 的 `enable_pbr` 和 `texture_resolution` 参数控制
- 几何+纹理 → `enable_pbr: true`, `texture_resolution: 'high'`
- 几何白模 → `enable_pbr: false`, `texture_resolution: 'none'`

### 3. 几何精度
控制3D模型的生成质量：
- **标准**：快速生成，适合快速预览和原型设计
- **超清**：精细建模，适合高质量输出和最终产品

**实现**：通过 Meshy API 的 `mode` 参数控制
- 标准 → `mode: 'preview'`
- 超清 → `mode: 'production'`

### 4. 文生3D
通过文字描述生成3D模型：
- 输入提示词：例如"一把复古风格的椅子"
- 使用 Meshy 的 `text-to-3d` API
- 支持所有模型参数（面数、类型、精度）

## 代码修改详情

### 1. Meshy API 服务层修改

#### `/workspace/projects/src/lib/meshy-api.ts`

**扩展 MeshyConfig 接口**：
```typescript
interface MeshyConfig {
  apiKey: string;
  mode: 'text-to-3d' | 'image-to-3d';
  style?: 'realistic' | 'anime' | 'sculpture' | 'low-poly';
  // 新增3D模型专用参数
  faceCount?: string; // '2m' | '1.5m' | '1m' | '500k'

  geometryPrecision?: 'standard' | 'ultra'; // 标准 | 超清
}
```

## 使用说明

### 用户操作流程（文生3D）

1. **选择生成模式**：点击"文生3D"按钮
2. **输入提示词**：在文本框中描述想要的3D模型
   - 例如：一把复古风格的椅子、一座城堡、一只卡通小狗
3. **选择模型面数**：
   - 2m：最高精度，细节最丰富
   - 1.5m：高精度
   - 1m：中等精度
   - 500k：低精度，性能好
4. **选择模型类型**：
   - 几何+纹理：带材质和颜色
   - 几何白模：纯白色，只显示结构
5. **选择几何精度**：
   - 标准：快速生成
   - 超清：精细建模
6. **生成模型**：点击"开始生成"按钮
7. **预览和下载**：在3D查看器中预览，点击下载按钮保存

### 用户操作流程（图生3D）

1. **选择生成模式**：点击"图生3D"按钮
2. **上传图片**：点击上传区域，选择参考图片
3. **选择图片模式**：单张图片或多张图片
4. **调整参数**：模型面数、模型类型、几何精度
5. **生成模型**：点击"开始生成"按钮
6. **预览和下载**：在3D查看器中预览，点击下载按钮保存

## 已知限制

1. Meshy API 可能不支持某些参数组合，需要根据实际API调整
2. 模型面数的精确控制可能受API限制，返回的面数可能不完全匹配
3. 文生3D的质量取决于提示词的描述详细程度
4. 超清模式的生成时间会明显增加
