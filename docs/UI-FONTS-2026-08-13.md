## 1. 字体族（font-family）

```css
--font-sans:
  'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei',  /* 中文优先 */
  ui-sans-serif, system-ui,
  -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,  /* 英文 */
  'Helvetica Neue', Arial, sans-serif;

--font-mono:
  ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas,
  'Liberation Mono', 'Courier New', monospace;
```

**主字体** = 中文优先（PingFang SC → Microsoft YaHei）→ 英文（system-ui → -apple-system → Segoe UI）

**位置**：`src/app/globals.css` `@theme inline`

---

## 2. 基础配置

```css
/* === globals.css body === */
body {
  font-family: var(--font-sans);
  line-height: 1.6;
  letter-spacing: 0.01em;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  font-size: 16px;  /* Tailwind v4 默认 base */
}
```

| 维度 | 值 |
|------|---|
| **默认正文** | 16px |
| **行高** | 1.6 |
| **字间距** | 0.01em |
| **抗锯齿** | antialiased |

## 5. 字重（font-weight）

| class | 值 | 用途 |
|-------|----|------|
| `font-thin` | 100 | 未用 |
| `font-extralight` | 200 | 未用 |
| `font-light` | 300 | 未用 |
| `font-normal` | 400 | 默认正文 |
| `font-medium` | 500 | 菜单项、表格标题 |
| `font-semibold` | 600 | 主要按钮、主标题 |
| `font-bold` | 700 | 大数字、字段标题 |
| `font-extrabold` | 800 | 未用 |
| `font-black` | 900 | 未用 |

**核心使用**：
- `font-medium`（500）—— 菜单、表格标题
- `font-semibold`（600）—— 主按钮
- `font-bold`（700）—— 大数字、字段标题

## 6. 行高（line-height）

```css
leading-none   → 1
leading-tight   → 1.25
leading-snug    → 1.375
leading-normal  → 1.5
leading-relaxed → 1.625
leading-loose   → 2
```

**全局默认 1.6**（写在 `body`）：宽松阅读体验。

**特殊位置**：
- 折叠按钮组 → `leading-none`（避免大按钮内文字偏）
- 表格头 → `leading-snug`（紧凑列表）

---

## 7. 字母间距（letter-spacing）

```css
tracking-tighter  → -0.05em
tracking-tight    → -0.025em
tracking-normal   → 0
tracking-wide     → 0.025em
tracking-wider    → 0.05em
tracking-widest    → 0.1em
```

**实际使用**：
- `tracking-[3px]`（Sidebar 顶部 COMMAND 装饰）
- `tracking-widest`（登录页"DUNHUANG GOLD AI DESIGN"）
- `tracking-wide`（部分副标题）


## 10. 修改字体/字号速查

### 常用场景

| 场景 | 应改 |
|------|-----|
| **Sidebar 折叠后图标太小** | 14px → 16px（`text-base`） |
| **登录页 H2（欢迎回来）太小** | 24px → 30px（`text-3xl`） |
| **所有 main text 太大** | globals.css `--text-base: 1.125rem`（18px） |
| **font-mono 不一致** | 各处需确认 `font-mono` 与 Tailwind 一致 |

### 修改流程

1. **改 size**：`.text-{size}` → `.text-{newsize}` 或 globals.css 改 `--text-{size}`
2. **改 family**：globals.css `--font-sans` 调整
3. **改 weight**：`.font-medium` → `.font-semibold`

⚠️ **注意**：所有改动必须**同步** globals.css @theme + 组件 class。

### 验证字体生效

```bash
# 浏览器开发者工具
F12 → Console → 输入:
getComputedStyle(document.body).fontFamily
# 应输出: "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", ...

getComputedStyle(document.body).fontSize
# 应输出: 16px
```

## 12. 字体加载性能

```css
/* globals.css 没有 font-display 显式设置 */
/* 浏览器默认: 'auto' 行为 */
/* 优化建议（如加载外部字体）: */
@font-face {
  font-family: 'PingFang SC';
  font-display: swap;  /* 先显示 fallback 后加载正式 */
}
```

**当前**：Pure system fonts（无外部下载），加载无延迟。
