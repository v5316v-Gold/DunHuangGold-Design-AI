# 文案生图参数实现文档

## 概述

本文档说明"文案生图"功能中分辨率和图片比例参数的实际实现效果。

## 参数说明

### 1. 分辨率（Resolution）

控制生成图片的输出分辨率，影响图片的清晰度和文件大小。

| 选项 | 基准尺寸 | 适用场景 | 生成速度 | 文件大小 |
|-----|---------|---------|---------|---------|
| 1K | 1024px | 快速预览、快速迭代 | 快 | 小 |
| 2K | 2048px | 推荐选择，平衡质量和速度 | 中等 | 中等 |
| 4K | 4096px | 最高质量，适合最终产品 | 慢 | 大 |

**使用说明**：
- 1K：适合快速查看效果，节省算力和时间
- 2K：大多数场景的最佳选择，质量与速度平衡
- 4K：适合最终产品、印刷品、高清展示

---

### 2. 图片比例（Ratio）

控制生成图片的宽高比，影响图片的形状和适用场景。

| 选项 | 宽高比 | 宽高比数值 | 适用场景 | 示例输出（2K分辨率） |
|-----|-------|-----------|---------|---------------------|
| Auto | 自动 | - | 根据提示词自动决定 | 2048x2048（正方形） |
| 1:1 | 正方形 | 1.0 | 社交媒体头像、Instagram | 2048x2048 |
| 2:3 | 竖版 | 0.666 | 手机海报、竖版设计 | 1365x2048 |
| 3:2 | 横版 | 1.5 | 经典照片比例 | 2048x1365 |
| 3:4 | 竖版 | 0.75 | 标准竖版照片 | 1536x2048 |
| 4:3 | 横版 | 1.333 | 传统显示器、老电视 | 2048x1536 |
| 4:5 | 竖版 | 0.8 | Instagram竖版 | 1638x2048 |
| 5:4 | 横版 | 1.25 | 经典横版照片 | 2048x1638 |
| 9:16 | 手机竖屏 | 0.5625 | 手机视频、短视频 | 1152x2048 |
| 16:9 | 宽屏 | 1.777 | 高清视频、宽屏显示器 | 2048x1152 |
| 21:9 | 超宽屏 | 2.333 | 电影、超宽显示器 | 2048x880 |

**使用说明**：
- Auto：让AI根据提示词内容自动决定最合适的比例
- 1:1：适合社交媒体分享（Instagram、微信朋友圈）
- 16:9：适合视频封面、横屏展示、PPT配图
- 9:16：适合手机视频封面、短视频平台
- 其他比例：根据特殊需求选择

## 实现逻辑

### 分辨率映射

```typescript
const baseSize = resolution === '1k' ? 1024 : resolution === '2k' ? 2048 : 4096;
```

### 比例计算逻辑

```typescript
if (ratio === 'auto') {
  // 自动：保持正方形
  finalWidth = baseSize;
  finalHeight = baseSize;
} else {
  // 解析比例（例如 "16:9"）
  const parts = ratio.split(':');
  const ratioWidth = parseInt(parts[0]);  // 16
  const ratioHeight = parseInt(parts[1]); // 9
  const aspectRatio = ratioWidth / ratioHeight; // 1.777

  if (aspectRatio > 1) {
    // 宽图：宽度为基准，计算高度
    finalWidth = baseSize;
    finalHeight = Math.round(baseSize / aspectRatio);
  } else {
    // 竖图：高度为基准，计算宽度
    finalHeight = baseSize;
    finalWidth = Math.round(baseSize * aspectRatio);
  }
}
```

## API调用示例

### 示例1：2K分辨率 + 16:9宽屏

```bash
curl -X POST http://localhost:5000/api/generate-image \
  -H 'Content-Type: application/json' \
  -d '{
    "prompt": "敦煌飞天，飘逸灵动",
    "resolution": "2k",
    "ratio": "16:9"
  }'
```

**输出尺寸**：2048x1152

**计算过程**：
- 基准尺寸：2048（2K）
- 宽高比：16:9 = 1.777 > 1，宽图
- 宽度：2048
- 高度：2048 / 1.777 ≈ 1152

## 实际效果说明

### 分辨率的影响

| 分辨率 | 清晰度 | 适用场景 | 注意事项 |
|-------|-------|---------|---------|
| 1K | 基础清晰度 | 快速预览、小尺寸展示 | 不适合印刷 |
| 2K | 良好清晰度 | 大多数场景 | 推荐 |
| 4K | 高清晰度 | 最终产品、印刷品 | 文件大，生成慢 |

### 比例的影响

| 比例 | 适用场景 | 示例 |
|-----|---------|------|
| 1:1 | 社交媒体 | Instagram头像、微信朋友圈 |
| 4:3 | 传统媒体 | 旧照片、电视内容 |
| 3:4 | 竖版照片 | 传统相机竖拍 |
| 16:9 | 现代媒体 | 高清视频、现代显示器 |
| 9:16 | 移动媒体 | 手机视频、短视频平台 |
| 21:9 | 电影媒体 | 电影、超宽显示器 |

## 注意事项

1. **尺寸限制**：生成的图片尺寸会被限制在512px-4096px之间
2. **API兼容性**：某些API提供商可能不支持所有比例，可能会自动调整
3. **文件大小**：4K分辨率的图片文件会明显更大
4. **生成时间**：4K分辨率的生成时间会显著增加
5. **比例精度**：某些比例可能无法精确实现，API会根据实际能力调整

## 使用建议

### 日常使用（推荐）
- 分辨率：2K
- 比例：Auto或16:9
- 理由：平衡质量、速度和兼容性

### 社交媒体分享
- 分辨率：2K
- 比例：1:1（Instagram）或16:9（Twitter）
- 理由：符合平台规范

### 印刷品
- 分辨率：4K
- 比例：根据印刷品要求
- 理由：保证印刷质量

### 快速预览
- 分辨率：1K
- 比例：Auto
- 理由：快速查看效果，节省算力
