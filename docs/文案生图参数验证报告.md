## 参数转换逻辑验证

### 分辨率转换

| 输入 | baseSize | 说明 | 验证状态 |
|-----|---------|------|---------|
| '1k' | 1024 | 1K分辨率 | ✅ |
| '2k' | 2048 | 2K分辨率 | ✅ |
| '4k' | 4096 | 4K分辨率 | ✅ |

**代码实现**：
```typescript
const baseSize = resolution === '1k' ? 1024 : resolution === '2k' ? 2048 : 4096;
```

---

### 比例转换

| 输入 | aspectRatio | 类型 | 基准方向 | 验证状态 |
|-----|------------|------|---------|---------|
| 'auto' | - | 自动 | - | ✅ |
| '1:1' | 1.0 | 正方 | - | ✅ |
| '2:3' | 0.666 | 竖图 | 高度 | ✅ |
| '3:2' | 1.5 | 横图 | 宽度 | ✅ |
| '3:4' | 0.75 | 竖图 | 高度 | ✅ |
| '4:3' | 1.333 | 横图 | 宽度 | ✅ |
| '4:5' | 0.8 | 竖图 | 高度 | ✅ |
| '5:4' | 1.25 | 横图 | 宽度 | ✅ |
| '9:16' | 0.5625 | 竖图 | 高度 | ✅ |
| '16:9' | 1.777 | 横图 | 宽度 | ✅ |
| '21:9' | 2.333 | 横图 | 宽度 | ✅ |

**代码实现**：
```typescript
if (ratio === 'auto') {
  finalWidth = baseSize;
  finalHeight = baseSize;
} else {
  const parts = ratio.split(':');
  const ratioWidth = parseInt(parts[0]);
  const ratioHeight = parseInt(parts[1]);
  const aspectRatio = ratioWidth / ratioHeight;

  if (aspectRatio > 1) {
    // 横图：宽度为基准
    finalWidth = baseSize;
    finalHeight = Math.round(baseSize / aspectRatio);
  } else {
    // 竖图：高度为基准
    finalHeight = baseSize;
    finalWidth = Math.round(baseSize * aspectRatio);
  }
}
```
