# 平面转雕塑参数实现文档

## 概述

本文档说明"平面转雕塑"功能中分辨率和图片比例参数的实际实现效果。

## 参数说明

### 1. 分辨率（Resolution）

控制深度图的输出分辨率，影响输出图像的清晰度。

| 选项 | 输出分辨率 | 纹理分辨率 | 适用场景 | 生成速度 |
|-----|-----------|-----------|---------|---------|
| 1K | 1024x1024 | low | 快速预览 | 快 |
| 2K | 2048x2048 | medium | 推荐，平衡质量与速度 | 中等 |
| 4K | 4096x4096 | high | 最高质量，适合最终输出 | 慢 |

**实现映射**：
```typescript
let outputResolution = 1024; // 默认1k
if (config.resolution === '1k') {
  outputResolution = 1024;
} else if (config.resolution === '2k') {
  outputResolution = 2048;
} else if (config.resolution === '4k') {
  outputResolution = 4096;
}

// Meshy API 参数
texture_resolution = config.resolution === '4k' ? 'high' : config.resolution === '2k' ? 'medium' : 'low';
```

---

### 2. 图片比例（Ratio）

控制输出图像的宽高比，影响图像的形状。

| 选项 | 宽高比 | 宽高比数值 | 适用场景 |
|-----|-------|-----------|---------|
| Auto | 自动 | null | 保持原图比例 |
| 1:1 | 正方形 | 1.0 | 社交媒体、头像 |
| 2:3 | 竖版 | 0.666 | 手机竖屏、海报 |
| 3:2 | 横版 | 1.5 | 经典照片比例 |
| 3:4 | 竖版 | 0.75 | 标准竖版 |
| 4:3 | 横版 | 1.333 | 传统显示器 |
| 4:5 | 竖版 | 0.8 | Instagram竖版 |
| 5:4 | 横版 | 1.25 | 经典横版 |
| 9:16 | 手机竖屏 | 0.5625 | 手机视频、短视频 |
| 16:9 | 宽屏 | 1.777 | 高清视频、宽屏显示器 |
| 21:9 | 超宽屏 | 2.333 | 电影宽屏、超宽显示器 |

**实现映射**：
```typescript
let aspectRatio = null;
if (config.ratio && config.ratio !== 'auto') {
  const parts = config.ratio.split(':');
  if (parts.length === 2) {
    const width = parseInt(parts[0]);
    const height = parseInt(parts[1]);
    if (width > 0 && height > 0) {
      aspectRatio = width / height;
    }
  }
}

// Meshy API 参数
{
  aspect_ratio: aspectRatio
}
```

## 参数组合建议

### 快速预览方案
- 分辨率：1K
- 比例：Auto
- 用途：快速查看效果，节省时间

### 标准输出方案
- 分辨率：2K
- 比例：根据目标选择（16:9视频、1:1社交媒体等）
- 用途：大多数场景的平衡选择

### 高质量输出方案
- 分辨率：4K
- 比例：根据目标选择
- 用途：最终产品、印刷品、高质量展示

### 特殊场景方案
- 手机短视频：2K + 9:16
- 微信朋友圈：2K + 1:1
- 横屏视频：4K + 16:9
- 电影海报：4K + 2:3

## Meshy API参数映射

### 请求体结构

```json
{
  "image_url": "https://...",
  "mode": "preview",
  "style": "realistic",
  "should_remesh": false,
  "enable_pbr": false,
  "generate_depth_map": true,
  "output_format": "png",
  "texture_resolution": "medium", // 由resolution参数控制
  "aspect_ratio": 1.777 // 由ratio参数控制（非auto时）
}
```

### 参数说明

| Meshy参数 | 来源 | 说明 |
|----------|------|------|
| texture_resolution | resolution | 'low' (1K) / 'medium' (2K) / 'high' (4K) |
| aspect_ratio | ratio | 宽高比数值（1.777, 0.5625等），auto时不传递 |
| generate_depth_map | 固定值 | 始终为true，生成立体深度图 |
| should_remesh | 固定值 | false，保留原始结构 |
| enable_pbr | 固定值 | false，不需要材质 |

## 实际效果说明

### 分辨率的影响
- **1K**：生成快速，文件小，适合快速预览和低分辨率输出
- **2K**：平衡选择，质量与速度适中，适合大多数场景
- **4K**：质量最高，文件大，生成时间长，适合高质量最终输出

### 比例的影响
- **Auto**：保持原图宽高比，最自然的选择
- **1:1**：正方形，适合社交媒体分享（Instagram、微信朋友圈）
- **16:9**：宽屏，适合视频、横屏显示器
- **9:16**：竖屏，适合手机视频、短视频平台
- **其他比例**：根据特殊需求选择

---

## 注意事项

1. **Meshy API限制**：Meshy API可能不支持所有比例参数，某些比例可能被忽略或自动调整
2. **文件大小**：4K分辨率生成的文件会明显更大，注意存储空间
3. **生成时间**：4K分辨率的生成时间会显著增加
4. **比例精度**：某些比例可能无法精确实现，API会根据实际能力调整

## 后续优化建议

1. **进度显示**：添加生成进度条，特别是4K分辨率需要较长时间
2. **预览缩略图**：先生成1K预览，用户确认后再生成高分辨率
3. **批量处理**：支持多张图片批量生成立体效果
4. **自定义比例**：允许用户输入自定义宽高比
5. **质量对比**：生成不同分辨率的对比图，帮助用户选择
