### 2. 🔴 pnpm 依赖结构修复（Windows 稳定性）
**问题**：pnpm 虚拟 store（`.pnpm/`）软链在 Windows 反复损坏（next/react/drizzle 集体失效，`@swc/helpers` 缺失）
**根因**：`.npmrc` 中 `verifyStoreIntegrity=false` + `strictStorePkgContentCheck=false` 跳过完整性校验，损坏静默通过

- 恢复 `verify-store-integrity=true` + `strict-store-pkg-content-check=true`
