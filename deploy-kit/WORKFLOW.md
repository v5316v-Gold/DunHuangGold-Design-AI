# 🔄 F盘部署流程图

## 整体流程

```
开始
  ↓
[检查F盘] → 失败 → 插入移动硬盘 → 返回
  ↓ 成功
[检查PostgreSQL] → 未安装 → 安装PostgreSQL 17 → 返回
  ↓ 已安装
[运行安装脚本]
  ↓
[设置数据库密码]
  ↓
[初始化数据库]
  ↓
[配置PostgreSQL]
  ↓
[启动PostgreSQL]
  ↓
[创建dunhuang_design数据库]
  ↓
[生成环境变量文件]
  ↓
[复制项目代码]
  ↓
[安装依赖] → 失败 → 检查网络/pnpm → 返回
  ↓ 成功
[运行数据库迁移]
  ↓
[启动服务]
  ↓
[访问应用]
  ↓
完成 ✅
```

## 决策树

### PostgreSQL安装方式

```
需要安装PostgreSQL 17？
├─ 是
│  ├─ 能用winget？
│  │  ├─ 是 → winget install PostgreSQL.PostgreSQL
│  │  └─ 否 → 下载安装包手动安装
│  └─ 重启电脑
└─ 否
   └─ 验证安装：psql --version
      └─ 版本 >= 17？
         ├─ 是 → 继续
         └─ 否 → 升级或重新安装
```

### 启动服务方式

```
启动服务？
├─ 推荐方式
│  └─ 双击 start.bat
│     └─ 自动启动PostgreSQL和应用
├─ 备选方式1
│  └─ 命令行执行
│     └─ pnpm start（需先启动PostgreSQL）
└─ 备选方式2
   └─ 分别启动
      ├─ pg_ctl start（数据库）
      └─ pnpm start（应用）
```

## 时间预估

| 步骤 | 预估时间 | 说明 |
|-----|---------|------|
| 安装PostgreSQL | 5-10分钟 | 下载+安装+重启 |
| 运行安装脚本 | 2-3分钟 | 初始化数据库 |
| 复制项目代码 | 1-5分钟 | 取决于文件大小 |
| 安装依赖 | 5-15分钟 | 取决于网络速度 |
| 数据库迁移 | 30秒-1分钟 | 创建表结构 |
| 启动服务 | 30秒-1分钟 | 启动数据库和应用 |
| **总计** | **15-35分钟** | **首次部署** |

后续启动只需：30秒-1分钟

## 错误处理流程

```
遇到错误？
├─ 查看错误信息
│  ├─ 数据库相关 → 检查 pg.log
│  ├─ 应用相关 → 检查 app.log
│  └─ 其他 → 查看控制台输出
├─ 查阅文档
│  └─ FULL-GUIDE.md → 常见问题部分
├─ 尝试重试
│  ├─ 停止服务
│  ├─ 检查配置
│  └─ 重新启动
└─ 仍无法解决
   └─ 记录错误信息，寻求技术支持
```
